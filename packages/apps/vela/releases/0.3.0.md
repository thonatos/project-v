Vela 0.3.0 为 macOS 增加完整应用自动更新，并保持 iPhone 客户端的现有分发方式不变。

## 更新内容

- macOS 应用菜单新增“检查更新…”，使用系统原生更新界面展示、下载和安装稳定版本。
- 更新以完整 `Vela.app` 为单位，使 Rust host、Go Core、NSH runtime 与界面保持同一 build。
- 更新 ZIP 在解压前使用独立 EdDSA 签名验证；现有 SHA-256 与 GitHub Artifact Attestation 继续用于人工校验和构建来源证明。
- 更新安装复用正式退出清理；关闭窗口仍只隐藏应用并保持共享与转发运行。

## 已知限制

- 0.2.0 及更早版本不含更新器，需要手动安装本版本一次。
- 当前 macOS 产物仍使用 ad-hoc 签名且未经过 Apple 公证，Sparkle 更新签名不等于 Developer ID 签名或 Apple 公证。
- 首期仅支持稳定单通道的完整 ZIP，不包含强制更新、静默安装、beta 通道或 delta update。
