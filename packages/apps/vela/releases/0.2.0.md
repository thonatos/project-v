Vela 0.2.0 统一了 macOS 与 iPhone 客户端的交互和视觉语义，并改善了连接状态、原生控件、头像加载与异步刷新行为。

## 更新内容

- 重新组织 macOS 设置页，将相关选项合并为「连接与共享」和「隐私与诊断」，并修复原生开关首次点击回退、连续点击无法切换的问题。
- 新增 macOS「Tailscale 使用代理」设置。关闭后重启 Vela，Tailscale 控制面与 DERP 不再使用应用启动时继承的 HTTP/HTTPS 代理；头像请求不受该设置影响。
- 改进 macOS 设备、转发、日志、账户、表单与菜单的键盘焦点、选中态、禁用态和辅助功能语义。
- 改进 iPhone 服务菜单、页面返回、焦点恢复、外观选择宽度、原生图标与开关的主题响应。
- Gravatar 头像改由 Core 使用宿主网络下载，再交给界面显示；无头像、加载失败或关闭隐私设置时继续显示账户首字母。
- 加强状态所有权、原子更新、异步 latest-wins 和计时器清理，避免旧刷新结果覆盖新状态或页面卸载后继续写入。
- 收紧 UI 外部能力声明、WebView 导航和 OAuth/SSO 边界，并保持复制失败和连接错误可恢复。

## 验证

- macOS 与 iOS 的共享流程、原生控件、主题覆盖、可访问性语义、Core、签名和发布契约已纳入统一验证入口。
- 已在 Apple Silicon Mac、Mac mini 和 iPhone 17 Pro 上完成正式宿主验收。

## 已知限制

- 本次 GitHub Release 仅提供 Apple Silicon macOS 资产。iOS 构建仍通过开发签名安装，不提供公开 IPA。
- macOS 应用采用 ad-hoc 签名且未经 Apple 公证，首次打开仍需在系统设置中手动确认。
