# react-component

内部 React 组件库，使用 Vite 构建，Storybook 用于本地预览。

## 开发

```bash
pnpm -F react-component dev            # Vite 开发服务器
pnpm -F react-component storybook      # Storybook (6006)
pnpm -F react-component build          # 构建
pnpm -F react-component build-storybook
```

私有包，不发布；组件约定见 [`docs/7-conventions.md`](../../../docs/7-conventions.md)。
