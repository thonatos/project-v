# Spec Delta

## REMOVED Requirements

### Requirement: 真 3D 标签球

**Reason**: Tags 页面和公开标签浏览能力已下线。

**Migration**: 使用 Docs 分类和 Blog 栏目浏览内容。

### Requirement: 标签球交互

**Reason**: 标签球随 Tags 页面退役，不再提供拖拽、悬停或标签跳转。

**Migration**: 使用 Docs、Blog、Projects 的稳定导航入口。

### Requirement: 标签云 client-only 与降级

**Reason**: 站点不再渲染 3D 或 2D 标签云，也不加载 Three.js 相关代码。

**Migration**: 页面以静态可用内容和栏目导航呈现。
