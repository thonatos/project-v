# Spec Delta

## REMOVED Requirements

### Requirement: 共享配色配置

**Reason**: 公开标签组件和分类随机配色已移除，不再需要标签配色配置。

**Migration**: 栏目和分类使用全站语义色与文字层级。

### Requirement: Tag Badge 配色方案

**Reason**: 列表和详情页不再展示 Tag Badge。

**Migration**: Blog 显示稳定栏目，Docs 显示文档分类。

### Requirement: 标签列表页配色统一

**Reason**: 标签列表页已下线。

**Migration**: 旧标签地址迁移至 Blog，站点不再维护标签页配色。
